# Clarity — Digital Solutions Landing Page

A single-page landing site for a digital solutions company, built with vanilla **HTML5**, **CSS3**, **Bootstrap 5**, and **JavaScript**.

🔗 **Live Demo:** https://mahmoudahmed992005.github.io/clarity-website/

## ✨ Features

- 🧩 Interactive tech-stack tabs
- 💬 Animated testimonials carousel
- ❓ FAQ accordion
- 📩 Full contact form

## 🛠️ Tech Stack

| Category | Technology |
|---|---|
| Markup | HTML5 |
| Styling | CSS3, Bootstrap 5 |
| Interactivity | JavaScript |

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/Mahmoudahmed992005/clarity-website.git

# Navigate into the project
cd clarity-website
```

### Run

No build step required — just open `index.html` directly in your browser, or serve it with a live server:

```bash
# Using VS Code Live Server extension, or:
npx serve .
```
